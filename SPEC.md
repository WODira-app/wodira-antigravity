# WODira integration, version 1

Create a standalone public repository at `WODira-app/wodira-antigravity`, with source in `~/code/wodira-antigravity`. Publish a release installable from GitHub, then submit it to the Antigravity Marketplace partner intake form. Marketplace acceptance is controlled by Google; a submitted application is not an approved listing.

The plugin connects directly to `https://api.wodira.app/mcp` using Streamable HTTP and OAuth authorization-code/PKCE. WODira advertises CIMD rather than DCR. Publish separate public client metadata documents with JSON content types on this repository's GitHub Pages site: Antigravity's HTTPS callback and Gemini CLI's explicitly configured loopback callback. Neither client contains a secret or a token. Request standard identity/refresh scopes and `organizer:ai`, subject to the account's consent and WODira's server-side permissions. Do not configure private commerce, CRM or admin access.

Deliver native Antigravity and Gemini CLI manifests, a bundled WODira square logo, five discoverable skills, narrowly scoped shared usage guidance, installation/troubleshooting documentation and reproducible package checks. Resolve tools from the live catalog and read the server's domain resources instead of publishing a stale exhaustive tool list. Include box demand KPIs/PDF export and Peak workflows only to the extent exposed by the public connection. Respect role, organization, revision, confirmation, idempotency and data-coverage constraints.

Validate the public package invariants, Antigravity's strict validator and installation discovery, unauthenticated MCP discovery/challenge, hosted metadata content type/identity and pre-consent OAuth redirects. Do not use a private account's data or execute business mutations for release verification. Keep build logs, temporary profiles and archives out of Git. Do not change the WODira application or production deployment.
