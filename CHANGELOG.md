# Changelog

## 1.0.0 — 2026-10-29

- Native Antigravity plugin and Gemini CLI extension for WODira's public Streamable HTTP MCP.
- Separate public CIMD clients for Antigravity's HTTPS callback and Gemini CLI's loopback callback, without bundled account credentials.
- Five skills covering connection, athlete activity, event operations, box demand/PDF reports and Peak planning workflows.
- Shared account, organization, confirmation and data-coverage guidance; no automatic tool trust or private MCP profile configuration.
- WODira branding, English/Spanish documentation, package checks and public OAuth discovery/metadata verification scripts.
